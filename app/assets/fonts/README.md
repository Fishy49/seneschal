# Fonts

Self-hosted webfonts, referenced from `app/assets/tailwind/application.css`.

| Family | Weights | Source | License |
|---|---|---|---|
| Cabinet Grotesk | 700, 800 | fontshare.com (Indian Type Foundry) | ITF Free Font License |
| Switzer | 400, 500, 600 | fontshare.com (Indian Type Foundry) | ITF Free Font License |
| JetBrains Mono | 400, 500 | fontsource (latin subset) | SIL Open Font License 1.1 |

Cabinet Grotesk carries display duty (page titles, the wordmark), Switzer is
the UI face, JetBrains Mono owns data: ids, costs, tokens, durations, logs.
